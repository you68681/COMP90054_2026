Lecture recap · Core update rule

TD targets and the general weight-update rule

The TD target comes from the RL algorithm; the weight update comes from the function approximator.

New notation on this slide: δ (delta) = temporal-difference (TD) error, the target minus the current Q-value estimate; ∇w Q̂ = gradient of the estimated Q-value with respect to the weight vector w (how changing each weight affects Q̂); φ(s,a) = feature vector for state s and action a; w₀, w₁ and φ₀, φ₁ are their individual components. α (alpha) is the learning rate defined earlier.
Step 1 · TD error

Q-learning chooses the highest estimated next-action value:

δ = r + γ maxa′ Q̂(s′,a′;w) − Q̂(s,a;w)

SARSA uses the action actually selected next:

δ = r + γ Q̂(s′,a′;w) − Q̂(s,a;w)

Both compare a reward-plus-future estimate against the current prediction. No extra target symbol is needed.

Step 2 · Error and weight update

General semi-gradient update:

w ← w + α δ ∇w Q̂(s,a;w)

For a linear model:

Q̂(s,a;w) = w₀φ₀(s,a) + w₁φ₁(s,a)
∇w Q̂(s,a;w) = φ(s,a)
w ← w + α δ φ(s,a)
Next: Why is the gradient equal to the features? We will unpack that with a concrete [2,4] example, then calculate a weight update. The full SARSA tutorial question remains at the end.
Preserve these general equations as the reference. Explain that the next two slides expand—not replace—the gradient identity and the numerical update. Distinguish Q-learning's max from SARSA's selected action.
Lecture recap · 3 minutes

Why does the gradient equal the features?

The gradient answers a simple question: if we change one weight, how much does our Q-value change?

Start with the linear prediction

Q̂(s,a;w) = w₀φ₀(s,a) + w₁φ₁(s,a)

Let φ(s,a) = [2, 4] and w = [0.1, −0.2].

Q̂ = 2w₀ + 4w₁ = −0.6

The features 2 and 4 are fixed for this state–action pair. The weights can change.

Change one weight at a time
Small weight changeQ-value change
w₀ increases by 0.012 × 0.01 = +0.02
w₁ increases by 0.014 × 0.01 = +0.04

So Q̂ is twice as sensitive to w₁ as to w₀ in this example.

∂Q̂/∂w₀ = 2,   ∂Q̂/∂w₁ = 4

∇w Q̂(s,a;w) = [2, 4] = φ(s,a)

For a linear model, each partial derivative is the corresponding feature.

Key takeaway: The gradient tells us how strongly each weight affects the current prediction. This simple gradient-equals-features identity is specific to linear approximation.
Ask: “If I increase w₀ by 0.01, what happens to Q? What if I increase w₁ instead?” Have students answer before revealing the derivatives. Clarify that φ(s,a) stays fixed during this single update. Do not work through the final Linear SARSA problem yet.
Lecture recap · 2 minutes

From TD error to a weight update

1 · How wrong was the prediction?

δ = r + γ maxa′ Q̂(s′,a′;w) − Q̂(s,a;w)

For this Q-learning illustration: r = 0, γ = 0.9, the best next Q̂ = −0.5, and current Q̂ = −0.6.

δ = 0 + 0.9(−0.5) − (−0.6) = +0.15

Positive error: adjust the current prediction upward.

2 · How should each weight change?

Δw = αδ∇w Q̂(s,a;w) = αδφ(s,a)

With α = 0.2, δ = 0.15, and φ(s,a) = [2,4]:

Δw = 0.2 × 0.15 × [2,4]

= [0.06, 0.12]

wnew = [0.1, −0.2] + Δw = [0.16, −0.08]

Before: Q̂ = −0.60   →   After: Q̂ = 2(0.16) + 4(−0.08) = 0.00

The prediction increased, but it overshot the target (−0.45). One update need not land exactly on the target; α and feature size matter.

Compare with tabular RL: Tabular Q-learning directly changes one Q(s,a). Linear approximation updates shared w, which can also change predictions for other state–action pairs. SARSA replaces the max term with Q̂(s′,a′;w), using the action actually selected.
Explain each factor aloud: δ tells whether we need to go up or down, the gradient indicates how weights affect Q, and α controls step size. This is an illustrative Q-learning TD target; the fully worked SARSA transition is reserved for the standalone exercise.

Deep RL concepts · 2 minutes · DQN bridge

From linear Q-functions to DQN

The Q-learning idea stays the same. The way we represent and train Q-values changes.

1 · Linear approximation

Q̂(s,a;w) = wᵀφ(s,a)

φ(s,a): manually chosen feature vector
w: learnable linear weights

Use a TD error to update the shared weights.

2 · Deep Q-Network (DQN)

Qθ(s,a)

θ (theta): parameters of the online neural network.

The network learns intermediate features and predicts an action value for each action.

Online network · θ

Predicts Qθ(s,a) for the sampled current action. Its parameters are updated using gradient descent and backpropagation.

Target network · θ⁻

θ⁻ (theta minus) is a slower-updated copy of the online parameters. It supplies the next-state value for a more stable TD target.

Training sequence: Online prediction → target-network TD target → squared TD error (loss) → backpropagation updates θ. Next slide: write this process as one equation.
Teaching note: Point to the earlier linear update before revealing the DQN difference. Distinguish θ from θ⁻; the target network's output is treated as fixed during an online-network gradient step. This target-network detail is supplementary DQN context; the uploaded Week 9 lecture presents deep Q-learning conceptually and marks it not examinable.

Suggested explanation: “The online network is the model we train. The target network has the same architecture, but its weights are copied from the online network only periodically. That makes our learning target more stable.”

DQN concepts · 3 minutes · Extended explanation

Why do we need two Q-networks?

Same architecture, different jobs: the online network learns; the target network supplies a slower-changing reference.

Two networks, two update schedules

OnlineTarget
Parametersθ (theta)θ⁻ (theta minus)
RoleCurrent Q predictionNext-state TD target
Gradient descent?Yes, every training stepNo, not directly
UpdateBackpropagationPeriodically copy θ
θ⁻ ← θ
Synchronise target parameters with online parameters periodically.

Gridworld: the moving-target problem

Assume r = 0, γ = 0.9, current prediction Qθ(s,a) = 0.4, and next-state maximum 0.6.

TD target = 0 + 0.9 × 0.6 = 0.54

If the same online network now changes its next-state estimate to 0.8, the target moves to 0.72 — even for the same sampled transition.

With a target network: the reference stays at 0.54 until the next target-network update (assuming the sampled transition is unchanged).

Analogy: The online network is a student revising its answers. The target network is a reference answer that is refreshed occasionally — it is not necessarily the true answer.
Suggested teaching script: “If the network changes its own prediction and its target at the same time, it may chase a moving target. The target network gives it a relatively stable reference. After some training steps, we copy the online weights into the target network.” Scope: Supplementary DQN material for Quiz 3 and Quiz 6; the Week 9 lecture labels neural-network details not examinable.
Training · Quiz 3 · 2 minutes

How is the neural value function trained?

L(θ) = [ r + γ maxa′ Qθ⁻(s′,a′) − Qθ(s,a) ]²

The online network uses parameters θ; the target network uses θ⁻. For a terminal transition, omit the future-value term.

Bridge to linear TD: in linear approximation the gradient is a feature vector; in deep RL backpropagation computes gradients through the network. Point out that SGD minimises squared TD error.
Neural Q-functions · Quiz 4 · 2 minutes

What does DQN approximate?

Input: state. Output: one estimated action value per action.

Technical nuance: Q^π is the best of the provided options, although canonical DQN aims at Q*. Do not confuse this with learning a policy network.
DQN update · Quiz 5 · 3 minutes

Which expression is the DQN TD target?

Think back to the Q-learning bootstrap target. Which option combines the observed reward with the best estimated value at the next state?

TD target = r + γ maxa′ Qθ⁻(s′,a′)

r = immediate reward; γ = discount factor; a′ = candidate next action; θ⁻ = target-network parameters. For terminal transitions, TD target = r.

Why C? The quiz writes Qθ, a simplified Q-learning expression. Standard DQN computes the next-state value using the slower-updated target network Qθ⁻. In both cases, the important idea is reward plus discounted maximum next-action value.
Ask students to vote before revealing the formula. Once they answer, unpack the TD target and explain why a terminal transition has no bootstrap term.
DQN stability · Quiz 6 · 2 minutes

Why a separate target network?

If both sides of the TD update change rapidly, the model chases a moving target.

Why A is correct

Online θ: changes through gradient descent. Target θ⁻: is held fixed between periodic synchronisations. This slows changes in the bootstrap TD target.

Do not confuse with Double DQN

Standard DQN uses a target network for stability. Double DQN additionally separates next-action selection from evaluation to reduce overestimation bias.

Key takeaway: Target networks make the training target more stable; they do not guarantee that the target is correct.
Distinguish DQN target networks from Double DQN: Double DQN decouples selection and evaluation in its target to reduce overestimation bias.
Lecture recap · feature engineering · 1 minute

Three ways to represent a Gridworld state

Different features let a linear model learn different patterns. Let s = (x, y), with x and y denoting grid coordinates.

METHOD 1 · DISTANCE

How far from each terminal?

φ(s) = [d₊(s)/5, d₋(s)/5]

d₊(s) is Manhattan distance to the +1 terminal; d₋(s) is distance to the −1 terminal.

Problem: nearby positive and negative terminals make these features poor indicators of the best route.

METHOD 2 · PROGRESS

First go up, then right

φ(s) = [y/2, 1{y=2} · x/3]

The second feature counts rightward progress only on the top row. The indicator 1{y=2} equals 1 when y = 2, otherwise 0.

Problem: at s = (0,0), both features are zero.

METHOD 3 · BIAS

Add a constant feature

φ(s) = [1, y/2, 1{y=2} · x/3]

The first feature is always 1, allowing a learnable baseline.

Fixes forced-zero predictions, but cannot repair every bad feature design.

Use the original Week 9 4×3 grid: one +1 terminal, one −1 terminal, and a wall. The lecture tried three different hand-designed feature vectors. Name d as Manhattan distance and the indicator before writing the expression. Explain that φ means feature vector.
Lecture recap · concrete example · 1 minute

Why do the second and third methods behave differently?

Method 2: forced zero

At the bottom-left state s = (0,0):

φ(s) = [0, 0]
V̂(s;w) = w₀·0 + w₁·0 = 0

The lecture gives the optimal value at this state as approximately 0.5452. No choice of weights can make this feature representation predict it.

Method 3: add a bias

For the same state, use a constant feature:

φ(s) = [1, 0, 0]
V̂(s;w) = w₀

Now the model can predict a nonzero value. For example, w₀ = 0.5 gives V̂(s;w) = 0.5.

Key takeaway: The TD update cannot rescue a representation that cannot express the correct value. The next problem tests one Linear SARSA update and then asks how to redesign features for a goal inside the grid.
Explain V̂ as the estimated state-value function and w as its weight vector. Ask students: “Would training longer fix Method 2 at (0,0)?” Answer: no, because zero features always force a zero prediction. This is a representational limitation, not simply a lack of experience.

Standalone problem · interpretation · 2 minutes

Why is this a SARSA update?

SARSA uses the chosen next action

δ = r + γ Q̂(s′,a′;w) − Q̂(s,a;w)

Here a′ = Right, so we evaluate its predicted next position (3,4).

Q-learning would use a maximum

δ = r + γ maxa′ Q̂(s′,a′;w) − Q̂(s,a;w)

We would compare all four possible next actions, rather than use only the chosen Right action.

Common mistake to avoid: In the weight update, use ∇wQ̂(s,a;w) = [2,4] (the current pair), not [3,4] (the next pair). Only one weight update is performed, and it changes the shared weights from [0.1, −0.2] to [0.16, −0.08].
You can ask: “If the next action had been Left, which part of the equation would change?” The next-action Q̂ would change, but the current-pair feature [2,4] would still determine the gradient.
Challenge question · 2 minutes

What if the goal is in the middle?

Challenge question (new scenario): Suppose the reward +1 is moved from corner (9,9) to an interior position such as (5,5). How should we change the feature representation so the goal can be preferred from either side?

Raw-coordinate features can only represent monotonic preferences along each axis.

Q̂ = w₀x′ + w₁y′

Fix y′. As x′ increases:

  • If w₀ > 0: values always rise.
  • If w₀ < 0: values always fall.
  • If w₀ = 0: values do not change.

Ask the class

For a goal at (5,5), can a fixed linear raw-coordinate model assign (5,5) a higher value than both (4,5) and (6,5)?

No. A straight line cannot have a strict interior maximum.

Do not give the answer immediately. Let students verbalise why slope alone cannot express “move toward the middle, then move away”.
Challenge explained · raw-coordinate limitation

Why can’t raw coordinates prefer an interior goal?

At goal (5,5), an agent approaching from the left should move right, while an agent approaching from the right should move left.

What we want

Consider possible next positions on the same row (y′ = 5):

(4,5) →★ (5,5)← (6,5)
We need the goal to be worth more than BOTH neighbours:
Value(5,5) > Value(4,5)
Value(5,5) > Value(6,5)

These are conceptual next-position scores computed by the action-value approximation—not a separate change to the problem's definition of Q(s,a).

What raw features actually do

Q̂ = w₀x′ + w₁y′
y′ = 5 ⇒ Q̂ = w₀x′ + 5w₁

Keeping y′ fixed makes this a straight line in x′.

Weight w₀Prediction as x′ increases
w₀ > 0Always increases → prefers right
w₀ < 0Always decreases → prefers left
w₀ = 0Constant → no preference

Check with actual numbers

Set w₁ = 0. With w₀ = +1, the predicted scores for x′ = 4, 5, 6 are 4, 5, 6 (right is best). With w₀ = −1, they are −4, −5, −6 (left is best). Neither makes the middle strictly best.

Use distance to the goal instead of raw position.

Q̂ = −|x′−5| − |y′−5|

At (4,5), (5,5), (6,5), the scores are −1, 0, −1. Now the goal is best from either side.

Teaching cue: Pause after the numerical comparison. Ask: “Which way would the model prefer if we used w₀ = +1? What about −1?” Then reveal why a goal-relative feature creates a peak. This is an illustrative score function; it does not claim exact Bellman-optimal values.

Raw-coordinate problem

With Q̂ = w₀x′ + w₁y′, a fixed w₀ makes Q̂ move only upward, downward, or stay flat as x′ increases. It cannot make (5,5) strictly better than both (4,5) and (6,5).

Distance-based solution

Use goal-relative features. With negative distance weights, Q̂ is highest near the goal. For example, with w₀ = w₁ = −1 and absolute distances, values at (4,5), (5,5), (6,5) are −1, 0, −1.

Important: Distances are smallest at the goal, but Q-values are highest there only with suitably negative distance weights (or an equivalent sign convention).
Ask: “Why is a nonlinear feature compatible with linear approximation?” Because the Q estimate is linear in the trainable weights, even if the fixed feature function is nonlinear in coordinates.
Challenge solution · 3 minutes

Fix the representation: goal-relative features

Absolute distance

With trainable weights w₀ and w₁:

Q̂(s,a;w) = w₀|x′−xg| + w₁|y′−yg|

(xg,yg) denotes the goal coordinates; (x′,y′) is the position after taking action a.

φ(s,a) = [|x′−xg|, |y′−yg|]

Distance rises linearly away from the goal: a V-shaped feature.

Squared distance

Q̂(s,a;w) = w₀(x′−xg)² + w₁(y′−yg)²
φ(s,a) = [(x′−xg)², (y′−yg)²]

Penalises larger deviations more strongly: a parabolic feature.

Both are linear in the weights!

These are feature shapes, not Q-value shapes. Negative distance weights produce higher values near the goal.

Read this carefully: The blue curve is monotonic; the orange and green features are both zero at x = 5 and increase on either side. These curves plot feature values (not estimated Q-values). For example, negative distance weights reverse the preference and make the estimated Q-value greater nearer the goal.

Emphasise that the adjective “linear” refers to weights, not necessarily inputs. Absolute and squared coordinate distances are nonlinear transformations but their weighted sum is linear in w. Explain why squared distance increases more rapidly far from the goal, while absolute distance grows at a constant rate.
Standalone challenge · explain the key idea

Why is this still linear approximation?

A model is linear in the learnable weights, even if we transform the input coordinates nonlinearly.

Q̂(s,a;w) = wᵀφ(s,a) = w₀φ₀(s,a) + w₁φ₁(s,a)
Notation: s = current state; a = selected action; w = learnable weight vector; φ(s,a) = feature vector; x′ and y′ = position after action a; (xg, yg) = goal coordinates. Linear in w means that the features are multiplied by weights and summed—without squaring or multiplying the weights.

Absolute-distance features

φ = [|x′−xg|, |y′−yg|]
Q̂ = w₀|x′−xg| + w₁|y′−yg|

The absolute values transform the coordinates, not the weights.

Squared-distance features

φ = [(x′−xg)², (y′−yg)²]
Q̂ = w₀(x′−xg)² + w₁(y′−yg)²

The squares transform the coordinates, not the weights.

Say: “Linear does NOT mean that every feature must be a straight line in the coordinates. It means Q-hat is a weighted sum of fixed features.” Ask students what is being learned: the weights, not the goal coordinates or the feature formulas.
Standalone challenge · worked numerical check

Fix the position: what happens to the weights?

Set the goal to (5,5) and the position reached by an action to (3,4). Compute the features first; then write the model.

Absolute distance

φ = [|3−5|, |4−5|] = [2,1]
Q̂ = 2w₀ + 1w₁

The features are now the fixed numbers 2 and 1. Both weights appear to the first power.

Squared distance

φ = [(3−5)², (4−5)²] = [4,1]
Q̂ = 4w₀ + 1w₁

The features are now 4 and 1. The model is still linear in its weights.

Quick class check: Which is not linear in the weights? (A) 2w₀+w₁    (B) 4w₀+w₁    (C) 2w₀²+w₁
Answer: C. The term w₀² makes the model nonlinear in a learnable weight. Absolute and squared coordinate distances are perfectly compatible with linear weight updates.
Read out the arithmetic first; then ask: “Where is the square in the squared-distance case?” It is inside the feature calculation, not on the weight. With fixed feature definitions, the gradient with respect to w is still φ(s,a).
Standalone challenge · link back to learning

Different features, same linear update

Δw = α δ φ(s,a)    and    wnew = wold + Δw

What changes?

φ(s,a): the feature vector may contain raw coordinates, absolute distances, or squared distances.

These representations produce different predictions and different gradients.

What stays the same?

w: the model learns a weight for each feature.

α: learning rate; δ: temporal-difference (TD) error. The update retains the same form.

Takeaway: We can give a linear model more useful, nonlinear input features without changing it into a nonlinear-in-parameters model. The feature design changes what the agent can represent.
This is a conceptual extension of the lecture's feature-engineering discussion. Do not conflate the fixed-feature linear model with a neural network, which learns intermediate representations.
Optional extension · 1 minute

What is still missing?

Bias / intercept

Q̂ = w₀ + w₁|x′−xg| + w₂|y′−yg|

Without a bias, all distance features are zero at the goal. A constant feature provides a learnable baseline.

Obstacles and representation limits

  • Manhattan distance may be misleading when a wall blocks the direct path.
  • A useful representation may need obstacle or path information.
  • Generalisation can improve data efficiency or spread errors across states.
Precision: the distance-only formula has value zero at a zero-distance feature vector. In an actual terminating MDP, terminal rewards and termination must also be modelled correctly; bias alone does not solve obstacle planning.
